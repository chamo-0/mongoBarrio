# 🏙️ mongoBarrio# 🏙️ mongoBarrio
**Práctica de Acceso a Datos - Integración con MongoDB**

Este repositorio contiene un proyecto académico desarrollado para el módulo de Acceso a Datos. Su objetivo principal es demostrar la conexión 
y manipulación de una base de datos NoSQL(**MongoDB**) mediante **Java**, utilizando datos demográficos reales de los barrios de Tenerife.

## 🚀 Consultas y Operaciones Implementadas

El proyecto ejecuta una serie de consultas y agregaciones sobre la colección de datos para extraer estadísticas específicas:

*   **Cálculos de agregación:** Obtención de la población máxima y mínima total dependiendo del barrio.
*   **Filtros y ordenación:** Búsqueda y listado de los 5 barrios más pequeños (menor población).
*   **Conteos (Count):** Cálculo del número total de barrios registrados en la base de datos.
*   **Búsquedas por criterios específicos:** Consulta estimativa de la población femenina residente en el barrio de Ofra.

## 🛠️ Stack Tecnológico

*   **Lenguaje:** Java
*   **Base de Datos:** MongoDB (NoSQL)
*   **Driver/Conector:** MongoDB Java Driver

## 💡 Contexto del Proyecto

Esta actividad forma parte del ciclo superior de Desarrollo de Aplicaciones Multiplataforma (DAM), 
sirviendo como introducción práctica a las bases de datos orientadas a documentos y al uso de consultas complejas (Aggregation Framework) desde código backend.
